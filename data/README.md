# Dataset

This project uses a hotel customer dataset containing approximately 83,590 customer records and 31 variables.

The dataset includes customer demographics, booking behavior, stay history, revenue information, booking lead time, room nights, and repeat-guest activity.

## Key Variables

- Age
- AverageLeadTime
- LodgingRevenue
- OtherRevenue
- RoomNights
- BookingsCheckedIn
- DaysSinceLastStay

The dataset is used for educational and portfolio purposes to demonstrate customer segmentation using K-Means clustering.
