# Notebooks

This folder contains the Jupyter Notebook used for the Hotel Guest Segmentation analysis.

## Main Notebook

`01_guest_segmentation.ipynb`

The notebook covers:

- data loading and validation
- data cleaning
- feature engineering
- exploratory analysis
- feature scaling
- K-Means clustering
- Elbow Method
- Silhouette Score evaluation
- customer segment profiling
- business interpretation
- visualization
